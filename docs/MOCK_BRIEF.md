# 모의고사 문제 제작 안내 (작업자용)

선생님 요청: 올려 준 원본 기출 10문제(과정마다)를 **모의고사 3세트**로 만든다. **원본과 최대한 비슷하게, 예시(입력·return)만 다른 정도로.**
세트 n(1~3)은 원본 1~10번 문제를 하나씩 담는다. 같은 유형의 1·2·3회 문제는 서로 **예시·숨은 테스트(와 문장 속 '예를 들어'의 수치)만 다르다**.

먼저 `docs/CONTENT_SCHEMA.md`(데이터 형식)와 `docs/AGENT_BRIEF.md`의 '원본 위치' 표를 읽는다. 연습 문제 파일 `src/content/<과정>/tNN.json`은 형식 참고용으로만 본다(그 문제들은 원본과 다르게 만든 연습 문제다).

## 만들 것

- 파일: `src/content/<과정>/mock/tNN.json` (NN = 원본 문제 번호)
- 모양: 연습 파일과 같은 머리(`course`, `type`, `typeTitle`, `kind`, `skills`, `intro` — 연습 파일 tNN.json의 값을 그대로 복사) + `problems` **3개**
- id: `<과정>-m1-tNN`, `<과정>-m2-tNN`, `<과정>-m3-tNN` (예: `pyb-m2-t07`), version 1
- `steps`: `[]` (모의고사는 중간 점검 없이 실전처럼). `explain`(해설 2~4문장)은 꼭 쓴다.

## 원본과 같게 둘 것

- 상황(이야기), 함수 이름, 매개변수 이름·순서, return 형식, 매개변수 범위·조건
- 코드: 원본 문제지의 코드 구조 그대로(보조 함수 구성, 빈칸의 위치와 개수, 틀린 한 줄의 위치와 종류, 함수 작성 틀). 빈칸 표시는 `⟦1⟧`, `⟦2⟧`…로 바꾼다
- kind(빈칸 채우기 blank / 한 줄 수정 fix / 함수 작성 write)와 난이도
- 3세트 모두 같은 문장·같은 코드(예시와 그 설명, 문장 속 예시 수치만 다름)

## 다르게 할 것

- **예시 입력·return**: 원본 예시와 다른 값으로 새로 만들고, 1·2·3회끼리도 서로 다르게. 예시 설명도 새 값에 맞게
- **숨은 테스트**: 10~15개, 경계값 포함, 기댓값은 정답 코드를 실행해 만든다
- **문장 표현**: 원본 문장을 글자 그대로 옮겨 적지 않는다(저작권). 원본의 정보·순서·조건을 하나도 빠뜨리거나 바꾸지 말고, 같은 뜻을 시험지 말투(합니다체)로 다시 쓴다
- **원본 오류는 바로잡는다** (예: 예시가 조건과 안 맞음, 정답 코드 오타, 문장에 없는 매개변수 이름, 0을 어느 쪽으로 세는지 문장과 코드가 다름, 동점 규칙 없음 등). 고친 내용은 보고에 적는다
- fix: 원본에서 '틀린 줄'이 사실은 맞는 식이라 고칠 것이 없으면(예: 2급 6번), 원본과 같은 자리·같은 종류의 실제 버그가 되게 한 줄을 정한다. 틀린 코드는 예시에서 틀린 답을 내야 한다

## 작업 방법

1. 원본 문제지와 정답 포함본에서 해당 번호를 읽는다.
2. 스크래치 폴더(`/tmp/claude-0/-home-claude/f9ff8c2b-5b59-50ab-b880-76e35968603d/scratchpad/mock/<과정>-tNN/`)에 Python 생성 스크립트를 만들어 정답 코드로 기댓값을 계산하고 JSON을 쓴다(`ensure_ascii=False, indent=1`).
3. `python3 tools/validate.py src/content/<과정>/mock/tNN.json` → `✓ … 검수 통과`가 될 때까지 고친다.
4. 다른 파일은 건드리지 않는다. git 명령은 하지 않는다.
