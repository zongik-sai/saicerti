개인정보처리방침

saicerti(자격증 코딩 연습 사이트: 프로그래밍 Python 기본·심화, 프로그래밍 C 기본) · 시행일 2026년 11월 27일

saicerti는 서울인공지능고등학교 담당 교사가 수업용으로 운영하는 무료 연습 사이트입니다. 같은 학교의 배움 숲(saiedu)과 로그인 서버(Supabase)를 함께 쓰지만, 이 사이트의 기록은 과정별로 따로 저장됩니다. 광고를 하지 않고, 개인정보를 판매하거나 제3자에게 제공하지 않습니다.

1. 처리하는 정보

Google 로그인 정보이메일 주소, Google 프로필 이름, 프로필 사진 주소(Google이 로그인 때 제공하는 기본 정보). 비밀번호는 받지 않습니다.
학습 기록과정(프로그래밍 Python 기본·심화, 프로그래밍 C 기본)마다: 문제별로 맞힌 중간 점검 단계, 중간 점검을 마쳤는지, 정답을 본 중간 점검 단계, 해결했는지, 채점(제출) 횟수, 처음 해결한 시각, 해설·모범 답안을 해결 전에 본 시각, 마지막으로 기록한 시각
학생이 쓴 코드서버로 보내거나 저장하지 않습니다. 코드는 학생 브라우저 안에서만 실행되고 채점되며, 작성 중인 코드(초안)는 그 기기의 브라우저 저장소에만 남습니다(로그아웃하면 지워짐).
로그인하지 않고 풀 때로그인 정보를 받지 않습니다. 학습 기록과 코드 초안은 그 기기의 브라우저 저장소에만 남고 서버로 보내지 않으며, 선생님 화면에도 보이지 않습니다. 여러 사람이 함께 쓰는 컴퓨터라면 다른 사람도 볼 수 있으니, 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.

2. 이용 목적

  • 로그인한 학생이 어느 기기에서나 이어서 공부할 수 있게 학습 기록을 저장합니다.
  • 담당 선생님이 반 학생들의 과정별 진도(해결한 문제 수, 채점 횟수 등)를 확인해 수업에 활용합니다. 이 기록은 학생 브라우저가 계산해 저장하는 자기 학습 기록이며 평가 근거가 아닙니다.

3. 볼 수 있는 사람

  • 학생 본인: 자기 기록만 읽고 쓸 수 있습니다(데이터베이스 행 수준 보안).
  • 담당 선생님(지정된 선생님 계정): 과정별 반 전체 기록을 읽기만 할 수 있습니다.

4. 보관 기간과 삭제

  • 학습 기록은 해당 학년도 수업 기간 동안 보관하고, 학년도가 끝난 뒤 1년 안에 정리합니다.
  • 기록 삭제나 계정 삭제를 원하면 담당 선생님께 말해 주세요. 계정을 지우면 연결된 모든 학습 기록(배움 숲 기록 포함)이 함께 지워집니다.
  • 이 기기에 남은 코드 초안은 로그아웃하면 지워집니다. 로그인하지 않고 남긴 기록은 브라우저의 사이트 데이터를 지우면 사라집니다.

5. 처리 위탁

  • Supabase(로그인·데이터 저장), GitHub Pages(사이트 호스팅), Google(로그인)
  • 파이썬 실행 환경(Pyodide)과 C 채점기는 이 사이트에 함께 올려 두고 브라우저에서 실행하므로 코드가 외부로 나가지 않습니다.
